# MC - SDIR | AI Integration Mini-Lab

**Model Name**: Gemini 3 Flash Preview
**Source**: Google Generative AI API

The chatbot uses the Gemini Flash model through the Google Generative AI Python client.
The model processes both the uploaded document and the user’s prompt to generate answers related to the document.

I selected the Gemini Flash model because it is optimized for fast responses and interactive applications like chatbots.
It integrates easily with Python and supports document-based prompting, which allows the chatbot to answer questions
using the uploaded file as context. This makes it suitable for building a simple document assistant that focuses on
answering domain-specific questions instead of generating unrelated responses.

AI models can sometimes produce biased or inaccurate information because they are trained on large datasets collected
from many sources on the internet. These datasets may include social biases or incomplete information. Because of this,
AI outputs should not always be considered completely reliable.

In this project, the chatbot is designed to reduce these issues by answering questions only using the uploaded document
rather than relying entirely on the model’s general knowledge. This helps keep responses focused on the provided data
and reduces hallucinations. However, users should still review AI-generated responses critically. Responsible AI use
also requires transparency about how the system works and what model is being used. Developers should clearly
communicate that responses are generated by AI and may not always be perfectly accurate.
